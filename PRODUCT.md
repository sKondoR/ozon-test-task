## Capabilities and Constraints

- Веб-приложение на Next.js (App Router), React, TypeScript, Tailwind. Данные с сервера приходят через `@tanstack/react-query` и нативный `fetch`.
- Деплой — статический экспорт на GitHub Pages (`https://skondor.github.io/ozon-test-task/`). Поэтому нет серверного рантайма: никаких route handlers, server actions и чтения cookies/headers на сервере. Все данные загружаются на клиенте.
- Архитектура — Feature-Sliced Design, правила импортов проверяются автоматически.
- Интерфейс на русском языке (`lang="ru"`).
- В dev-зависимостях есть `openapi-typescript`, то есть, скорее всего, будет внешний API с OpenAPI-спецификацией. Не решено: какой API и где его спецификация.
